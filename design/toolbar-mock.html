Peekover — the toolbar mock (M13 task 3.1)

Design material for your written approval before any toolbar code. Not shipped. Nothing on this page loads from the network. Everything inside a frame is the proposal; the dashed control strip below is only for stepping through the frames.

Review guide — what to look at and decide

  1. Is everything you use in the toolbar? Mark, file name, agent badge, watch, Compare, Read / Edit / Raw, Theme, Code theme, Stored data, Export — and nothing that does not ship. State: Reading · Light · all widths.
  2. Is the order right? Document controls on the left (what you are reading), app controls on the right (how Peekover behaves). Reading · 1440.
  3. Does the Read / Edit / Raw switch read clearly, including while editing? Editing · both themes.
  4. Watching: is the pill clear? Ink text, green dot, green border (G-4). Watching · both themes.
  5. The one-time snapshot notice: right place and words? Below the toolbar, never over text; "Got it" and a Stored data link. Snapshot notice · 1440 and 414.
  6. Compare: does the picker belong under its button? Snapshots first, then other files. Compare open · 1440 and 414.
  7. At 1080 and 414 the toolbar wraps into rows (document controls, then app controls). Acceptable, or do you want something else (a decision, not a mock edit, if it changes the plan)? Reading · 1080 and 414.
  8. The "Files" button and overlay below 1080 px (the 1080 value is re-measured at task 4.8). Files overlay · 1080 and 414.
  9. The file name in the highlighter, dark theme: the proposal uses a full highlighter chip with dark text (the mockup's half-height marker leaves dark-theme text on yellow at 1.2:1). OK? Reading · Dark.
  10. The status line says only three things — the open file, "No network calls" / "Network: N requests you made", "Peekover 0.1.0". Enough? Reading, and Network used.
  11. The mark blinks (only when your system allows motion). Keep? Any state.
  12. Code colours, light — strings: the new #197E44, or --ink, or --muted? Section "Code theme" below.
  13. Numbers / constants: the new #B34F2E, or an alternative? Types / attributes: the new #966319, or an alternative? Code theme.
  14. Functions and tags have no colour of their own in the 5.8 mapping (shown as default text). Fine? Code theme.
  15. Bricolage at 20 px and 44 px: the shipped static files or the variable font with automatic optical size? Section "Optical size" below.
