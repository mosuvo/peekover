# Peekover
**Raw in. Reading out.** The free, open-source browser extension that turns raw markdown —
including the piles of it your AI agents write — into beautiful, instant reading.
Zero network calls. No telemetry. Free means free, permanently.

> Status: pre-release, building milestone 1 in the open. Site: https://peekover.dev

## The deal
No price, no tiers · no ads, no funnels · never sold (an ownership change voids the listing —
expect releases only from this repo) · yours to inspect (MIT, reproducible builds,
[annotated permissions](docs/trust/PERMISSIONS.md)).

## Contributing / building
See AGENTS.md (works for humans too). `pnpm dev` once milestone 1 lands.

named mobile apps — this project lives here and at peekover.dev, nowhere else.
