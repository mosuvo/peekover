# Brief — Peekover
**One line:** The trusted way to read the raw files computers (and AI agents) produce.
**Wedge:** markdown reader/editor extension, better than every incumbent (78 parity features,
36 firsts — see docs/product/spec.md). **Phase 2:** universal raw-file viewer (.json/.jsonl/.yaml/.toml/.csv).
**Why us:** AI agents now write more markdown than humans can read raw; incumbents are stale
(top one unmaintained since 2024), and the category just had a trust scandal (JSON viewer adware).
**Business model:** none, deliberately. Credibility/audience play. $0 infra (GitHub Pages, store fees only).
**Brand:** paper, ink, one highlighter. "Raw in. Reading out." Trust is shown, not claimed
(receipts: no servers, no telemetry, 0 network calls, reproducible builds).
**Success (v1):** ships on Chrome+Firefox+Edge, <150ms render, ≤7MB, a launch post worth reading.
