Debugging ritual (WORKFLOW.md 5.4). A bug report follows. Work read-only — do not edit any file yet:

1. Confirm or construct a reliable reproduction (command, test, or steps). If you cannot reproduce, stop and tell me what's missing.
2. Investigate and produce a one-paragraph diagnosis: current behavior, expected behavior, root cause, and what must NOT change.
3. Propose the failing test that would capture this bug.
4. Wait for my approval before writing the test or the fix.
