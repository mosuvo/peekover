IN PLAIN SIGHT

Other extensions say “trust us.”
We show receipts.

Extensions get sold, hijacked, and turned into adware — it happened to the most popular JSON viewer on the store. Peekover is architected so there’s nothing to betray you with.

  • No servers, ever. No backend to breach, no database to leak, no account to phish.
  • Zero network by default — the only calls possible are ones you trigger, each with a visible indicator.
  • Minimal permissions, requested per-origin at the moment of use — a published PERMISSIONS.md justifies every manifest line, and updates never silently add permissions.
  • Open source (MIT), reproducible builds — byte-comparable to the store artifact, signed releases, published SBOM, locked dependencies, a threat model in the repo, and a security hall-of-fame.
  • The ownership pledge: never sold, never ads or affiliate injection, never data collection. In writing, in the README.
