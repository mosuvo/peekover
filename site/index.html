FOR AGENT OUTPUT

Your agents write markdown all night.
This is where you read it.

Coding agents write CLAUDE.md files, specs, plans and changelogs faster than anyone can read them raw. Peekover renders them, and on the app page it can watch them and show what changed.

◉

Watch mode

Leave a document open and it re-renders when the file changes on disk, keeping your reading position. It works on the app page, and in Chromium-based browsers also in a tab showing a file opened from disk. Firefox has some limits; the README lists them.

Δ

What changed

On the app page, Peekover keeps snapshots on your device while it watches a document, and shows what changed since one of them.

⇆

Compare two files

On the app page, pick another markdown file in the folder and read the difference.

◈

Agent-file badge

CLAUDE.md, AGENTS.md, spec.md, plan.md and tasks.md get a badge saying what kind of file they are.

READING

Raw markdown in. A page out.

CommonMark with the GitHub additions for tables, task lists, strikethrough and bare links, cleaned before it reaches the page.

✒

The syntax

Tables, task lists, strikethrough, bare-URL links and inline HTML, all cleaned with DOMPurify before they are shown.

∑

Math & diagrams

On the app page: math rendered with Temml, Mermaid diagrams with a zoom view, and buttons to copy a formula as LaTeX or MathML and to copy or download a diagram.

{}

Code

On the app page: highlighting for JavaScript, TypeScript, TSX, Python, JSON, CSS, HTML, Bash, diff, YAML, Markdown, TOML and SQL, a choice of code themes, and copy, line numbers and wrap on each block.

▤

Folders

On the app page, opened from the toolbar button: open a folder, browse its markdown files, pin files and reopen recent ones.

☰

Contents

A table of contents rail for documents with two or more headings. Select a heading to jump to it.

◫

Tables

Sort, filter and copy any table.

Aa

Reading, your way

Light and dark themes that follow your system by default, a raw view, and the Literata reading face.

⚡

Never a blank page

If rendering fails, you get the raw text with an error banner. The whole extension is under 7 MB.

🌐

Sources

Markdown files opened from disk, and raw files on GitHub, GitLab and Bitbucket. Remote images stay blocked until you choose to load them.

ON THE APP PAGE

A reader first. An editor when you need it.

On the app page, Edit opens the markdown beside a live preview.

✎

Editor

A plain markdown editor beside a live preview. It asks before discarding unsaved changes.

▦

Save

Save writes the file back in Chromium-based browsers such as Chrome and Edge; in Firefox it downloads a copy. If the file changed on disk meanwhile, Save stops and tells you.

⟲

Snapshots

Kept on your device while a document is watched. Turn them off or erase them under Stored data.

⇩

Export

A standalone HTML file, print to PDF, and copy as HTML, plain text or rich text.

IN PLAIN SIGHT

Don’t take our word for it.
Read the receipt.

Peekover has no server of its own and asks for no browser permissions.

  • No servers. There is no backend, no database and no account.
  • No network by default. The only requests are ones you trigger, such as loading remote images, and the page shows an indicator when that happens.
  • No permissions. The manifest requests none; PERMISSIONS.md lists each capability used without one.
  • Open source (MIT). CI checks that no code is loaded from outside the package, audits the production dependencies, generates a software bill of materials, and checks that two builds of the same source are identical.
  • No ads, no paid tier, no telemetry. The code has none, and the tests check that the extension makes no network requests by default.

SETUP

From source to reading.

Build

Peekover is not in the stores yet. Build it from source with Node 22 and pnpm, as the README explains, and load the unpacked build.

Flip one switch

For files on your disk in Chromium-based browsers, turn on “Allow access to file URLs” for Peekover in the extension settings.

Peek

Open a markdown file from disk or a raw link, or open the app page from the toolbar button and pick a folder.
